HOW FX WORK IN THIS BUILD
  1. You press Q / E / R → Hero.useSkill(i, G) runs the ability (damage, knockback, its own rings and particles).
  2. That method calls Hero.playFX(G, i) — one line: what did the studio put in this skill's slot?
  3. fxpack.fxFor() answers: this slot's file → else the hero's ALL file → else nothing. Muted slots are skipped.
  4. fxpack.spawnFX() builds it from a pool: a clone of your .glb, or a billboard fed by one shared <video>, plus a light borrowed from the fixed pool.
  5. Your FX LOOK numbers drive that instance (scale, rise, spin, fade…) and a coroutine ticks it; at the end kill() returns everything. Nothing is created or destroyed per cast.
  6. CAST SIM (above) runs steps 1–5 for real, so an effect can be judged against the shake, the knockback and the ability's own burst — not on a blank stage.
  7. The bench owns the body while it is on. Its update runs the real Hero.move + Hero.update, so MOVE is what moves the hero, POSE can only overlay an envelope on top of a live cast, and walk frequency is measured off the hero's actual velocity instead of assumed. Turn the bench off and this loop drives the body by itself again (MOTION-AUDIT F4/F5).
